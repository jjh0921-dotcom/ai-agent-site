# ⚙️ NicheFlow AI MVP: 프로그래밍 포스트 초안 생성 로직 설계안

## 1. 목표 정의 (Goal Definition)

**최종 목표:** 사용자가 입력한 주제(Topic)와 난이도(Difficulty)에 기반하여, 검색 엔진 최적화(SEO)에 유리하고 독자의 참여를 유도하는 고품질의 프로그래밍 포스트 초안(Draft)을 자동 생성한다.

**핵심 기능:**
1. **입력 수집:** 주제, 타깃 독자, 원하는 포스트 스타일(후크 유형) 입력.
2. **프롬프트 엔지니어링:** 입력값을 바탕으로 LLM이 원하는 구조와 톤을 갖춘 초안을 생성하도록 유도.
3. **API 연동:** 외부 데이터(선택 사항) 또는 내부 지식베이스(Knowledge Base)를 참조하여 초안의 깊이를 보강.

## 2. 프롬프트 엔지니어링 설계 (Prompt Engineering Design)

핵심은 LLM이 단순히 코드를 나열하는 것이 아니라, **'교육적 가치'**와 **'흥미 유발'**을 결합한 구조화된 콘텐츠를 생성하도록 유도하는 것입니다.

### 2.1. 시스템 프롬프트 (System Prompt)

LLM의 역할과 제약 조건을 명확히 정의합니다.

```prompt
당신은 전문적인 기술 블로거이자, 복잡한 프로그래밍 개념을 명확하고 이해하기 쉽게 설명하는 교육 콘텐츠 전문가입니다. 당신의 목표는 사용자가 제공한 주제와 요구사항에 따라, 독자의 학습 수준에 맞춰 깊이 있고 실용적인 프로그래밍 포스트 초안을 작성하는 것입니다.

**[톤앤매너 지침]**
1. **톤:** 전문적이지만 친절하고(Friendly), 권위적(Authoritative)이어야 합니다.
2. **구조:** 모든 포스트는 명확한 논리적 흐름(Introduction -> Core Concepts -> Example/Code -> Conclusion/CTA)을 따라야 합니다.
3. **SEO 최적화:** 제목과 소제목(H2, H3)에는 핵심 키워드를 자연스럽게 포함해야 합니다.
4. **참고:** 항상 독자가 코드를 직접 실행해볼 수 있도록 명확한 예제 코드 블록을 포함해야 합니다.
```

### 2.2. 동적 사용자 프롬프트 (Dynamic User Prompt)

사용자 입력(Input Variables)을 기반으로 LLM에게 구체적인 지시를 내립니다.

| 입력 변수 | 설명 | 프롬프트에 반영될 내용 |
| :--- | :--- | :--- |
| **Topic** | 포스트의 핵심 주제 (예: 비동기 프로그래밍의 이해) | 포스트의 중심 내용 설정 |
| **Target Audience** | 타깃 독자의 기술 수준 (예: 초보자, 중급 개발자, 특정 언어 숙련자) | 사용될 용어의 난이도 및 예제 코드의 복잡도 결정 |
| **Post Style** | 원하는 포스트의 스타일 (예: 튜토리얼, 심층 분석, 비교 리뷰, 문제 해결) | 콘텐츠의 구조와 깊이 결정 |
| **Hook Type** | 도입부 후크 유형 (예: 충격적인 통계 제시, 문제 제기, 흥미로운 비유) | 도입부(Introduction)의 초안 생성 방식 결정 |

**예시 프롬프트 구조:**
> "위의 지침에 따라, [Topic: {입력값}]에 대해 [Target Audience: {입력값}]를 대상으로 [Post Style: {입력값}] 형식의 포스트를 작성해 주세요. 도입부 후크는 [Hook Type: {입력값}]을 사용하며, 핵심은 [핵심 개념 A, B, C]를 실용적인 예제 코드로 설명해야 합니다."

## 3. API 연동 로직 설계 (API Linkage Logic Design)

이 기능은 크게 세 단계의 API 호출로 구성됩니다.

### 단계 1: 입력 및 검증 API (Input & Validation API)

*   **입력:** `Topic`, `Target Audience`, `Post Style`, `Hook Type`
*   **기능:** 사용자의 입력이 MVP의 제약 조건(예: 허용된 주제 범위, 최소 요구 정보)을 충족하는지 검증합니다.
*   **출력:** 유효성 검사 결과 및 프롬프트 구성 변수.

### 단계 2: 핵심 초안 생성 API (Core Draft Generation API)

*   **입력:** (단계 1에서 검증된 변수) + (시스템 프롬프트)
*   **기능:** LLM 엔진(예: GPT-4)에 최종적으로 구성된 프롬프트를 전송하여 포스트 초안을 생성합니다.
*   **출력:** 구조화된 포스트 초안 (제목, 목차, 본문 초안, 코드 블록).

### 단계 3: 후처리 및 최적화 API (Post-Processing & Optimization API)

*   **입력:** (단계 2에서 생성된 초안) + (선택적 데이터 소스)
*   **기능:**
    1. **SEO 점수 계산:** 생성된 제목과 본문의 키워드 밀도를 분석하여 SEO 점수를 부여합니다.
    2. **톤 보정:** 생성된 텍스트가 설정된 '회사 정체성' 톤앤매너(자가학습된 톤)에 부합하는지 검토하고 미세 조정합니다.
    3. **CTA 삽입:** 본문 마지막에 사용자가 정의한 CTA(Call-to-Action)를 자연스럽게 삽입합니다.
*   **출력:** 최종 사용자에게 제공될 완성된 포스트 초안.

## 4. 데이터 흐름 시각화 (Data Flow Visualization)

**사용자 입력** $\rightarrow$ **API 1 (검증)** $\rightarrow$ **프롬프트 템플릿 구성** $\rightarrow$ **API 2 (LLM 생성)** $\rightarrow$ **API 3 (후처리/최적화)** $\rightarrow$ **최종 포스트 초안**
