# 💻 코다리 — MVP(Minimum Viable Product)의 핵심 기능 정의(네이밍 시스템, 포토카드 연동, 결제 흐름)를 정의하고, 서버 론칭에 필요한 기술 스택 및 초기 API 구조 설계에 대한 로드맵을 제시하라.

한 번에 요청하신 내용을 종합하여, 프로젝트의 다음 단계를 위한 **로드맵 및 기술 스택 제안**을 제시합니다.

현재 단계는 **기획 구체화 및 기술 설계** 단계이며, 이 단계를 성공적으로 완료해야 실제 개발 단계로 넘어갈 수 있습니다.

---

## 1단계: 핵심 기능 정의 및 데이터 모델 설계 (기획 구체화)

가장 먼저, 시스템이 수행해야 할 핵심 기능을 명확히 정의하고 데이터 구조를 설계해야 합니다.

### 1. 핵심 기능 정의 (MVP Scope)

| 기능 영역 | 세부 기능 (MVP) | 설명 |
| :--- | :--- | :--- |
| **사용자 관리** | 회원가입/로그인 | 기본적인 사용자 인증 및 세션 관리. |
| **이름 생성** | 이름 추천 시스템 | 사용자가 원하는 스타일(귀여움, 클래식, 독특함 등)에 따라 이름 추천 알고리즘 제공. |
| **결과 생성** | 이름 및 컨셉 조합 | 추천된 이름과 선택된 컨셉을 조합하여 최종 결과물(이미지/텍스트) 생성. |
| **결제 시스템** | 결제 연동 | Stripe 또는 국내 PG사 연동을 통한 안전한 결제 처리. |
| **결과 제공** | 결과물 다운로드 | 생성된 이름 및 컨셉을 포함한 디지털 결과물(이미지/PDF) 제공. |

### 2. 데이터 모델 설계 (Schema)

필요한 핵심 데이터베이스 테이블 구조를 정의합니다.

*   **Users Table:** 사용자 정보 (ID, 이메일, 결제 정보 등)
*   **Name_Concepts Table:** 이름 스타일 및 컨셉 정의 (예: 귀여움 레벨, 테마, 성별 등)
*   **Generated_Results Table:** 사용자가 생성한 최종 결과물 저장 (사용자 ID, 생성된 이름, 선택된 컨셉, 생성 일시, 파일 경로)

## 2단계: 기술 스택 제안 (Technology Stack)

MVP를 빠르게 구현하고 확장성을 확보하기 위한 기술 스택을 제안합니다.

### 1. 프론트엔드 (Frontend)

*   **React.js / Next.js:** 빠른 프로토타이핑과 서버 사이드 렌더링(SEO)에 유리하여 초기 시장 진입에 적합합니다.
*   **Tailwind CSS:** 디자인 시스템을 일관성 있게 적용하고, 모바일 친화적인 반응형 디자인을 빠르게 구현할 수 있습니다.

### 2. 백엔드 (Backend)

*   **Node.js (Express/NestJS):** JavaScript 생태계를 활용하여 프론트엔드 개발자와의 협업이 용이하며, 비동기 처리에 강해 API 서버 구축에 효율적입니다.
*   **PostgreSQL / MongoDB:** 데이터의 관계성(사용자, 결제)이 중요하므로 **PostgreSQL**을 주 데이터베이스로 사용하고, 생성 결과물 메타데이터는 **MongoDB**로 보조 저장하는 하이브리드 구조를 고려합니다.

### 3. 핵심 AI/생성 엔진 (Core Generation Engine)

이 부분이 서비스의 핵심 가치를 결정합니다.

*   **LLM (Large Language Model):** **OpenAI API (GPT-4o)** 또는 **Claude 3**를 활용하여 사용자의 입력(스타일 키워드)을 받아 창의적인 이름과 컨셉 설명을 생성합니다. (가장 빠르고 고품질의 텍스트 생성 가능)
*   **Image Generation (선택 사항):** **Midjourney API** 또는 **Stable Diffusion API**를 연동하여 텍스트 설명을 기반으로 고품질의 결과 이미지(예: 이름 컨셉 아트)를 생성하여 제공합니다.

### 4. 인프라 및 배포 (Infrastructure & Deployment)

*   **클라우드:** **AWS** 또는 **Vercel** (프론트엔드 호스팅)
*   **DB:** **AWS RDS** (PostgreSQL)
*   **AI API 관리:** 서버리스 함수(AWS Lambda)를 통해 API 호출을 관리하여 비용 효율성을 확보합니다.

## 3단계: 개발 로드맵 (Development Roadmap)

이 로드맵은 3~4개월 집중 개발을 기준으로 설계되었습니다.

| 단계 | 목표 | 주요 산출물 | 예상 기간 |
| :--- | :--- | :--- | :--- |
| **Phase 1: 기획 및 설계** | 데이터 모델 확정 및 API 명세서 작성 | 최종 DB 스키마, API 명세서 | 2주 |
| **Phase 2: 백엔드 구축** | 사용자 인증, DB 연결, AI API 연동 로직 구현 | 로그인/결제 API, 이름 생성 로직 백엔드 | 4주 |
| **Phase 3: 프론트엔드 개발** | 사용자 인터페이스(UI/UX) 구현 및 API 연동 | 반응형 웹 UI, 이름 생성 인터페이스 | 4주 |
| **Phase 4: 통합 및 테스트** | 전체 시스템 통합 및 결제 흐름 테스트 | End-to-End 테스트 완료, 보안 점검 | 2주 |
| **Phase 5: 배포 및 런칭** | 최종 QA 및 서비스 배포 | 운영 환경 배포 완료 | 1주 |

**총 예상 개발 기간: 약 13주**

## 최종 조언: 성공을 위한 핵심 포인트

1.  **AI 프롬프트 엔지니어링:** LLM API 호출 시, 원하는 '귀여움', '클래식' 등의 추상적인 키워드를 구체적인 프롬프트로 변환하는 **프롬프트 엔지니어링**에 가장 많은 시간을 투자해야 합니다. 이것이 서비스의 차별화 포인트입니다.
2.  **결제 보안:** 결제(Payment) 부분은 절대 직접 처리하지 말고, **Stripe**와 같은 검증된 외부 서비스를 사용하여 보안 위험을 최소화해야 합니다.
3.  **반복적 개선 (Iteration):** MVP 출시 후 사용자 피드백을 즉시 반영하여 이름 생성 알고리즘과 UI를 지속적으로 개선해야 합니다.
